LiveHub 首个正式版本：社区自部署的多主播直播平台。

## 快速开始

```bash
docker run -d --name livehub --restart unless-stopped \
  -p 8000:8000 -p 1935:1935 -p 10080:10080/udp \
  -v livehub-data:/data \
  ghcr.io/awrhs/livehub:1.0.0
```

打开 `http://<服务器IP>:8000`，第一个注册的账号自动成为管理员。完整说明见 [部署文档](https://github.com/Awrhs/streaming_media_server/blob/main/docs/DEPLOY.md)。

镜像支持 `linux/amd64` 与 `linux/arm64`。

## 功能

**观众**
- 直播列表、分类、搜索；直播封面与观看人数
- 网页播放三种模式：标准（HLS）、低延迟（HTTP-FLV，1–3 秒）、超低延迟（WebRTC，需配置 `LIVEHUB_WEBRTC_CANDIDATE_IP` 并开放 UDP 端口）
- 开启转码后多清晰度自动切换
- 实时聊天；关注主播并接收开播通知；录像回放（可拖动）
- 中文 / English 界面

**主播**
- OBS RTMP 推流与 SRT 推流；推流码随时重置
- 直播标题、分类、简介；自动录像，下播后生成回放
- 任命房管；删除消息、禁言

**管理员**
- 注册方式（开放 / 邀请码 / 关闭）、开播审批
- 用户管理：角色、封禁（立即断流并注销会话）
- 举报处理、审计日志、站点公告
- 聊天慢速模式、屏蔽词；录像保留天数；多清晰度转码开关
- 运维命令：在线备份、重置密码、设置管理员

**部署与扩展**
- 单容器部署：Go 平台 + 内嵌前端 + C++ 媒体服务器（崩溃自动重启）
- 边缘节点分担播放带宽（`LIVEHUB_EDGE_URLS`），自动健康检查与回落
- 推流鉴权 fail-closed：平台不可用时拒绝推流

## 安全

- 密码 bcrypt 哈希；会话 token 仅存摘要；HttpOnly + SameSite Cookie
- 写操作 CSRF 防护（自定义请求头 + Origin 校验）
- 登录 / 注册按 IP 限流，账号连续登录失败锁定 15 分钟
- 聊天按用户限速，单 IP 聊天连接数上限

## 已知限制

- 平台为单实例（SQLite）；水平扩展通过边缘媒体节点分担播放流量。
- 推流码以明文存储在数据库中（便于主播随时查看），请妥善保护数据目录。
- WebRTC 播放的音视频未做 RTCP 同步，长时间播放可能出现轻微音画偏差。
